# Звук «Кубохода»

Все игровые эффекты воспроизводятся из локальных WAV-файлов. Генерации тонов осцилляторами больше нет. Для перекатов используются три записи удара по дереву, для интерфейса — два варианта короткого клика. Победа, раскрытие секрета и награда используют короткие музыкальные записи pizzicato.

## Источники и лицензии

Автор эффектов — **Kenney**. Исходные наборы распространяются под **CC0 1.0** и допускают коммерческое использование:

- [Impact Sounds](https://kenney.nl/assets/impact-sounds): перекаты, падение и стекло.
- [Interface Sounds](https://kenney.nl/assets/interface-sounds): кнопки, переключатели, отмена, подсказка, начало уровня, портал, монета и недоступное действие.
- [Music Jingles](https://kenney.nl/assets/music-jingles): pizzicato для победы, раскрытия и награды.

Копии лицензий находятся в `dist/assets/sfx/LICENSE-*.txt`. Файл `dist/assets/sfx/manifest.json` содержит исходное имя каждого файла, ссылку на набор, SHA-256 исходника и готового WAV, размер и длительность. Используются 17 отдельных записей, всего около 410 КБ. Во время игры внешние серверы для загрузки звуков не нужны.

`dist/assets/music.mp3` — отдельно предоставленная пользователем музыка. Лицензии Kenney на неё не распространяются.

## Подготовка файлов

Исходные OGG размещались локально в `tmp/audio-source/{impact,interface,jingles}/Audio/`. Скрипт `scripts/prepare-sfx.cjs` декодирует их через настоящий браузерный аудиодекодер, сводит в моно, обрезает тишину, применяет короткие входной и выходной fade и нормализует пик до −3 dBFS. Результат — **32 кГц, 16 бит, PCM WAV**: формат поддерживается в Chrome, Android WebView и Safari без зависимости от поддержки OGG.

Скрипт нужен только для повторной подготовки ассетов. Готовые WAV уже находятся в репозитории; для публикации игры перекодирование не требуется.

## Воспроизведение

`audio.preload()` загружает и декодирует эффекты заранее. Он не включает звук, не создаёт музыкальный плеер и не загружает MP3. После первого пользовательского жеста `audio.unlock()` разрешает воспроизведение. Декодированные буферы кэшируются; повторные вызовы не загружают файлы заново.

Одновременно активно до восьми эффектов. Длинные музыкальные награды заменяют предыдущую мелодию. Консервативные уровни громкости и общий компрессор ограничивают перегрузку при наложении. Если Web Audio недоступен, короткие эффекты воспроизводятся через HTML Audio.

Выключение звуков, скрытие вкладки и пауза рекламы останавливают активные эффекты. Звук, не успевший загрузиться до рекламы, не воспроизводится после её завершения. Настройки музыки и эффектов независимы. MP3 по-прежнему зациклен на громкости 0.25, запускается после жеста и сохраняет позицию после паузы.

## События

| Событие | Звук |
| --- | --- |
| `move`, `step` | Один из трёх деревянных перекатов |
| `tap`, `pause`, `equip` | Один из двух коротких кликов |
| `switch` | Механический переключатель |
| `undo`, `back` | Короткий обратный щелчок |
| `hint` | Подсказка |
| `start` | Открытие уровня |
| `fail`, `fall` | Глухой удар |
| `glass` | Стеклянный удар |
| `portal` | Погружение |
| `win`, `complete`, `success` | Победное pizzicato |
| `coin`, `buy`, `purchase` | Получение/покупка |
| `reveal` | Раскрытие секретного предмета |
| `reward` | Награда за видео |
| `blocked`, `error`, `bump` | Недоступное действие |

## Проверки

`node --test tests/audio.test.mjs` проверяет прежнее поведение MP3, предварительную загрузку без автовоспроизведения, кэш, варианты перекатов, лимит голосов, отключение при рекламе/фоне, HTML Audio fallback, а также формат, лицензии, уникальность и контрольные суммы всех WAV.

Дополнительно в локальном Chrome проверены декодирование и воспроизведение всех событий без осцилляторов и ошибок JavaScript. При стресс-проверке восьми максимально громких одновременных записей пик выхода составил 0.946, ниже цифрового клиппинга. Локальный отчёт: `tmp/sfx-browser-qa.json`.
