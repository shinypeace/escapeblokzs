# КУБОХОД

Вертикальная браузерная головоломка: перекатывайте блок по белым платформам и поставьте его вертикально в отверстие. В проекте 120 уровней, шесть глав, магазин обликов и фонов за игровые монеты, анимированные правила, отмена хода и бесплатные подсказки из текущего положения.

Версия 2 обновляет интерфейс: короткие названия, крупные кнопки, растровые иконки и звёзды, компактные окна паузы и результата. На компьютере игра сохраняет пропорции экрана телефона; фон по бокам продолжает выбранную тему.

## Локальный запуск

Нужен **Node.js 18 или новее**. Устанавливать npm-пакеты для запуска и тестов не требуется.

```sh
npm start
```

Откройте [localhost:4173](http://localhost:4173). На Windows можно запустить **START.cmd**: он запускает сервер и открывает браузер. Для проверки на телефоне используйте локальный IP-адрес компьютера с портом `4173`.

Игра использует ES-модули, поэтому запускайте её через HTTP/HTTPS. Для статического хостинга достаточно содержимого папки `dist`.

## Управление и игра

- **Телефон:** свайпы по игровому полю.
- **Компьютер:** клавиши со стрелками. `Z` / `Backspace` — отмена, `R` — перезапуск с подтверждением, `H` — подсказка, `Esc` — пауза.
- Кнопки под полем: перезапуск, отмена и подсказка. Экранных стрелок управления нет.
- В паузе доступны продолжение и главное меню, а перезапуск и настройки представлены иконками.

Стоящий блок занимает одну клетку, лежащий — две. Победа засчитывается только в вертикальном положении над отверстием. С уровня 41 появляются хрупкие плитки, с уровня 61 — переключаемые мосты, с уровня 81 — два независимых переключателя. Последняя глава объединяет механики. Все 120 уровней имеют проверенное решение; подсказка рассчитывается из текущего состояния поля.

За прохождение и улучшение звёзд начисляются игровые монеты. Повтор уже достигнутого результата не приносит повторную награду. В магазине шесть обликов и шесть фонов; покупки меняют оформление. Превью заранее загружаются и декодируются при запуске. Превью обликов отрисованы тем же Canvas-рендерером и с теми же текстурами, что и игровой блок.

Анимация падения учитывает последнее опорное ребро и ускорение вниз. Поверхности платформ перекрывают блок по глубине. При победе блок опускается через точный контур отверстия, без просвечивания сквозь плитки и исчезновения через прозрачность.

## Сохранения и настройки

В обычном браузере, в том числе при прямом открытии GitHub Pages, прогресс хранится локально: уровни, монеты, покупки, выбранное оформление, настройки и незавершённая партия. Данные проверяются при загрузке; предусмотрены резервная копия и восстановление после повреждения. Очистка данных сайта удаляет локальное сохранение.

Настройки содержат четыре переключателя: звуки, музыка, вибрация и уменьшение анимации. Звуковые эффекты синтезируются через Web Audio. Фоновая музыка — предоставленный автором проекта файл `dist/assets/music.mp3`: воспроизводится по кругу после включения музыки и взаимодействия с игрой, выключатель сохраняется между запусками. При паузе рекламы или сворачивании музыка останавливается и затем продолжается с прежнего места. Вибрация зависит от поддержки устройства и браузера.

В **[VK App 54824611](https://vk.com/app54824611)** подключён официальный VK Bridge: получение пользователя, облачное хранение прогресса, отдельный локальный кеш для каждого VK-аккаунта и обработка сворачивания приложения.

Нижний баннер запрашивается постоянно в поддерживаемом VK-клиенте, когда доступно объявление. Место под него резервируется до загрузки SDK, а затем уточняется по размеру баннера, безопасной области и фактическому изменению WebView; медленные и неполные ответы не опускают кнопки под рекламу. Межэкранная реклама запрашивается только после победы или поражения: после каждой третьей завершённой попытки и не чаще одного раза за 90 секунд. Переход к следующему раунду ждёт завершения рекламного запроса; во время игры реклама не вызывается.

Настройка приложения, ограничения реальной выдачи рекламы, монетизация и устройство облачного хранения описаны в **[docs/VK.md](docs/VK.md)**. Показ настоящей рекламы требует подключения монетизации и выполнения требований VK в кабинете владельца приложения. Прямой запуск сайта вне VK работает с локальным сохранением.

## GitHub Pages

Репозиторий: **[shinypeace/escapeblokzs](https://github.com/shinypeace/escapeblokzs)**.

Целевой адрес после успешной публикации: **[shinypeace.github.io/escapeblokzs](https://shinypeace.github.io/escapeblokzs/)**.

Для первого развёртывания включите в репозитории **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow [.github/workflows/pages.yml](.github/workflows/pages.yml) запускается при отправке изменений в `main` или вручную через Actions. Сначала выполняются проверки, затем публикуется статическая папка `dist`. При ошибках проверок публикация не выполняется.

Тот же HTTPS-адрес нужно указать в настройках веб-версии и мобильной версии VK-приложения. Наличие workflow в репозитории само по себе не подтверждает, что Pages уже включён и сайт опубликован.

## Проверки и устройство проекта

```sh
npm run check
npm test
```

Проверки охватывают все 120 уровней, оптимальные решения, подсказки, хрупкие плитки и мосты, геометрию перекатов, перекрытие платформами и погружение в отверстие. Отдельные тесты проверяют локальные сохранения, разделение аккаунтов, облачное хранение, ошибки VK Bridge и момент вызова рекламы. Реальная выдача рекламы и синхронизация с VK проверяются внутри приложения VK.

```text
dist/
  index.html, styles.css   интерфейс и вертикальная компоновка
  app.js                  меню, партия, магазин, управление
  renderer.js             изометрическая геометрия и Canvas-анимация
  levels.js               120 уровней, правила и поиск решения
  storage.js              проверка и хранение прогресса
  vk-platform.js          аккаунт, облако, реклама и жизненный цикл VK
  audio.js                звук, музыка и вибрация
  assets/                 растровые фоны, текстуры и иконки
  vendor/                 локальная сборка VK Bridge и её лицензия
docs/VK.md                настройка VK Mini Apps
tests/                    проверки игры, рендера, сохранений и VK
server.mjs                локальный сервер без зависимостей
.github/workflows/pages.yml  проверка и публикация dist на Pages
```

SVG не используются. Новые иконки и звёзды созданы встроенным OpenAI ImageGen и подготовлены как PNG/WebP с прозрачностью. Исходный атлас и сведения о генерации находятся в `dist/assets/ui`; промпт и происхождение записаны в [dist/assets/ui/provenance.json](dist/assets/ui/provenance.json). Превью реальных игровых обликов воспроизводятся скриптом `scripts/render-shop-previews.mjs`; подготовка атласа — `scripts/prepare-ui-assets.py`. Эти вспомогательные скрипты требуют своих инструментов обработки изображений и браузерного рендера; для игры и `npm test` они не нужны.
